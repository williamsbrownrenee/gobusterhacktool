# Gobuster Hack Tool




The Gobuster Tool is powerful, fast directory, and file brute- forcing tool written in the go programming language, its used to find hidden directories, files, DNS subdomains and virtual host on web servers. The gobuster tool is being used in a control environment to hack and expose vulnerablities on Fakebank website.
